# Agentic Engineering là gì

Agentic Engineering là kỷ luật thiết kế, triển khai, đánh giá và kiểm soát các hệ thống AI có khả năng hành động. Nó nằm ở giao điểm của prompt engineering, software architecture, distributed systems, developer tooling, security và governance.

Prompt engineering tập trung vào cách yêu cầu model trả lời tốt. Agentic Engineering tập trung vào cách cả hệ thống ra quyết định và hành động đúng trong môi trường thật. Vì vậy, một prompt tốt chỉ là một phần nhỏ. Phần còn lại là context, tools, state, workflow, permission, eval và observability.

## Các câu hỏi trung tâm

- Agent biết mục tiêu bằng cách nào?
- Agent lấy context từ đâu và tin context nào?
- Agent có thể dùng tool nào, với quyền nào?
- Khi tool fail, agent retry hay dừng?
- Khi kết quả mơ hồ, agent tự quyết hay hỏi người dùng?
- Làm sao đo agent tốt hơn phiên bản trước?
- Ai chịu trách nhiệm nếu agent sửa sai, xóa nhầm hoặc lộ dữ liệu?

## Vì sao đây là engineering

Một hệ thống agent có side effect. Nó có thể tạo PR, gửi email, gọi API, đọc secrets, cập nhật ticket, tạo invoice hoặc deploy code. Khi hệ thống có side effect, ta cần các nguyên tắc engineering cổ điển: boundary, type, contract, logging, testing, rollback và ownership.

## Một định nghĩa làm việc

Agentic Engineering là quá trình biến năng lực suy luận của model thành hành động có kiểm soát trong một môi trường cụ thể. Nếu model là động cơ, Agentic Engineering là khung xe, phanh, cảm biến, bảng điều khiển, luật giao thông và quy trình bảo trì.
