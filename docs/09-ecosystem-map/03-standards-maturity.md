# Standards Maturity

Không phải chuẩn nào cũng trưởng thành như nhau. Một số đã có adoption mạnh, một số mới là đề xuất, một số là convention cộng đồng. Đánh giá maturity giúp tránh đặt cược sai.

## Tiêu chí maturity

- Có nhiều implementation độc lập không.
- Có tài liệu ổn định không.
- Có security model rõ không.
- Có backward compatibility không.
- Có ecosystem tool thật không.
- Có governance hoặc maintainer rõ không.

## Maturity matrix

| Nhóm | Maturity tương đối | Nhận xét |
|---|---|---|
| MCP | Cao hơn trong nhóm agent protocols | Adoption nhanh, vẫn cần hardening security |
| A2A | Đang phát triển | Quan trọng cho interoperability, còn cần thực chiến |
| ACP | Đang phát triển | Hữu ích để nghĩ về agent runtime contract |
| Instruction files | Convention thực dụng | Dễ dùng nhưng chưa chuẩn hóa mạnh |
| Multi-agent frameworks | Không đồng đều | Nhiều ý tưởng tốt, production quality khác nhau |

## Kết luận

Hãy thiết kế để thay đổi được. Với ecosystem non-stationary, abstraction boundary quan trọng hơn chọn đúng tên công cụ ngay từ đầu.
