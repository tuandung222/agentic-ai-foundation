# Maturity Matrix

| Chủ đề | Maturity | Ghi chú thực dụng |
|---|---|---|
| MCP | Khá cao | Nên học sớm vì adoption nhanh, nhưng cần permission và supply-chain review. |
| A2A | Đang hình thành | Quan trọng cho interoperability, chưa nên over-engineer nếu workflow nội bộ đủ. |
| ACP | Đang hình thành | Hữu ích để nghĩ về agent runtime, cần theo dõi ecosystem. |
| `AGENT.md` | Thực dụng | Dễ áp dụng ngay, portable hơn file riêng từng vendor. |
| `CLAUDE.md` | Thực dụng trong hệ Claude | Tốt cho Claude Code, nên tránh chứa rule mâu thuẫn với `AGENT.md`. |
| Skills | Đang chuẩn hóa theo sản phẩm | Rất hữu ích nếu viết như module năng lực tái dùng. |
| Multi-agent swarm | Không đồng đều | Dễ demo, khó production nếu thiếu ownership và eval. |
| Trace-based evals | Rất quan trọng | Nên xây từ sớm nếu agent có side effect. |
